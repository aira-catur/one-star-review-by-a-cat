# One-Star Review by a Cat

A single-line, one-star review written by a house cat about the human it lives with — deadpan review form, complaint only a cat would make. Entry for the make.fun bounty [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

Run `python3 main.py` to write the review line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (or `/output`).
